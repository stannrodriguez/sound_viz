# Sound Physics Visualizer

Interactive visualizations for exploring how sound works, from air pressure waves to digital audio and frequency analysis.

Live site: [https://stannrodriguez.github.io/sound_viz/](https://stannrodriguez.github.io/sound_viz/)

## Sections

- **Sound Chain**: Air molecule movement, ear and brain processing, and digital audio processing stages.
- **Notes**: Interactive C4 to B4 note player with adjustable harmonic amplitudes.
- **Harmonics**: Fundamental frequency and harmonic amplitude mixer with live audio playback.
- **Sound Waves**: Interactive explorer for sine, square, sawtooth, and triangle wave shapes.
- **Fourier Transform**: Time-domain and frequency-domain views of wave shapes and their harmonics.
- **Audio Analysis**: Spectrogram and waveform analysis view for an audio clip.

## Scripts

- `npm run dev`: Start the Vite development server.
- `npm run build`: Build the app for production.
- `npm run preview`: Preview the production build locally.
- `npm run lint`: Run ESLint across the project.
- `npm run deploy`: Deploy the `dist` directory to GitHub Pages.
